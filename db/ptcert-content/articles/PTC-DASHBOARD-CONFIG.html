Configurações necessárias para usar o dashboard

Site das licenças

Se tivermos um hardock com o ID 123456 temos de criar um hardlock chamado 123456hardlock com o módulo YEARLY. Se isto não existir, o sistema que recebe os dados do dashboard não os vai guardar.

Se não fizermos, ao aidiconarmos o ID em dashboard.ptcert.com não aparecerão dados.

Dashboard com password

Caso se pretenda definir uma password para o dashboard, tem de se fazer isso nas configurações do programa (pesquisar por dashboard, existe um parâmetro para isso).

Depois de o fazer, em dashboard.ptcert.com onde vamos inserir o id do hardlock temos de colocar (no caso do exemplo acima) 123456password (sendo que “password” seria o valor que definimos para o código de acesso ao dashboard).
