Guia Instalação Drivers Hardlock TP-LINK e MT7601Usta em .TIBs antigas

Este documento serve como guia de instalação dos drivers TP-LINK e MT7601Usta.

Existem duas maneiras de efetuarmos a instalação.

Uma consiste em ter internet na máquina e descarregar diretamente os drivers, a outra consiste em instalar em modo offline através dos ficheiros numa pen.

COM INTERNET

É necessário então termos um teclado ligado ao POS de forma a abrir uma linha de comandos através do atalho ALT+1.

Para descarregarmos os drivers:

TP-Link:

wget http://software.ptcert.com/downloads/hardlock_tplink.zip

MT7601Usta:

wget http://software.ptcert.com/downloads/hardlock_mt7601.zip

Posteriormente necessitamos de descompactar o ficheiro, correspondente aos drivers que queremos instalar:

Para os TP-Link:

unzip hardlock_tplink.zip

Para os MT7601:

unzip hardlock_mt7601.zip

Após descompactar, de forma a correr o script de instalação, teremos de entrar no diretório onde o mesmo se encontra.

Para aceder aos ficheiros que acabamos de descomprimir, temos de utilizar o comando “cd”.

Para os TP-LINK:

cd hardlock_tplink/

Para os MT7601:

cd mt7601usta-master/

Agora que entramos no diretório onde se encontra o script de instalação.

Para o correr temos de efectuar o seguinte comando (tanto para os TP-Link como para os MT7601):

./install.sh

Deixamos este processo terminar, pelo que quando terminar recomendamos retirar e voltar a colocar o hardlock e reiniciar o software terminando assim a instalação dos mesmos. De forma a confirmar se a máquina já detecta o hardlock, acedemos ao INFO MÁQUINA através do login na conta de técnico/administrador/gerente, DIVERSOS > UTILITÁRIOS.

SEM INTERNET

Para instalarmos através da pen é necessário descomprimir os ficheiros anteriormente mencionados para uma pen (para a raíz da mesma) para os descarregar é só aceder aos links que estão nos comandos.

Introduzir então a PEN no POS, com um teclado abrimos uma linha de comandos através do atalho ALT+1.

Para acedermos à pen é necessário descobrir o caminho correcto, executamos o comando:

cd /media/

Neste directório encontram-se todos os dispositivos de armazenamento amovíveis, para descobrir o directório onde a pen está montada fazemos o seguinte comando “ls”:

ls

Irá apresentar todos os diretórios disponíveis.

Se só tivermos uma pen, por norma apenas aparece o directório “usbhd-sdb1”, se tivermos mais podemos ter vários desde “usbhd-sda1”, “usbhd-sdc1” etc., podemos ir entrando nos directórios para descobrir a pen, fazendo o comando “ls” para ver os ficheiros e o comando “cd ..” para navegarmos para recuarmos no diretório.

No caso de termos só uma pen acedemos então ao dispositivo:

cd usbhd-sdb1/

Para confirmarmos que estamos no diretório correto, utilizamos o comando “ls” e devemos de ver todos os ficheiros que estão na raiz da pen.

Acedemos então à pasta correspondente dos hardlocks:

Para os TP-LINK:

cd hardlock_tplink/

Para os MT7601:

cd mt7601usta-master/

E corremos o script de instalação através do comando:

./install

Após terminar, reforçamos novamente:

Deixamos este processo terminar, pelo que quando terminar recomendamos retirar e voltar a colocar o hardlock e reiniciar o software terminando assim a instalação dos mesmos. De forma a confirmar se a máquina já detecta o hardlock, acedemos ao INFO MÁQUINA através do login na conta de técnico/administrador/gerente, DIVERSOS > UTILITÁRIOS.

Terminamos assim a instalação dos drivers.
