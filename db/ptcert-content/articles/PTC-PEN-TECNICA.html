Criação Pen Técnica

Objetivo:

Ter o conhecimento para a criação de uma pen técnica para a instalação de POS

Ferramentas Necessarias:

Fazer download dos seguintes softwares nos respectivos links:

Yummi: http://software.ptcert.com/downloads/yumi.exe

Acronis: http://software.ptcert.com/downloads/Acronis2017.iso

Imagem PTCert: http://software.ptcert.com/downloads/ptcert2_202101_v1.tib

Maquinas Suportadas: http://software.ptcert.com/downloads/machines_u17.zip

Como Fazer:

Após ter feito todos os downloads acima descritos para o seu computador em windows seguir os passos abaixo descritos

Abrir o yummi e seleccionar a opção “I Agree” como exemplifica a imagem abaixo.

Escolher a pen correcta.

Seleccionar a caixa para formatar a pen.

Escolher a opção “Try an unlisted ISO.

No Browse escolhemos o Acronis 2017.iso.

Fazer create para iniciar o processo.

Após escolher as operações acima descritas irá aparecer as imagens que apresentaremos abaixo, deveremos responder afirmativamente a pergunta que nos informa as operações que serão feitas pelo Yummi no processo de criação da pen.

Após todas as tarefas estarem concluídas será apresentada a imagem abaixo em que carregamos em next, para passarmos a fase seguinte

Neste quadro permite-nos escolher:

Adicionar mais algum ISO a pen de arranque

Finalizar o processo de criação

Após colocaros o(s) iso(s) que pretendemos carregar em finish para terminar todo o processo.

No final de tudo devemos fazer o seguinte:

Descompactar o ficheiro Machines_U17.zip

Copiar a pasta para a raiz da pen

Copiar para a raiz da pen o ficheiro ptcert2_… .tib

Criar na pen uma pasta POS, esta pasta serve para

Colocar Ficheiros excel para importar

Backups das instalações que fazemos

...

Deverá ficar com uma pen semelhante a imagem abaixo
