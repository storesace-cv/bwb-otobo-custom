Produtos

Os menus são criados a partir de >> Tabelas >> Famílias / Produtos.

Vamos explorar a criação de produtos para menus.

Em >> Tabelas >> Famílias/Produtos deve criar as famílias e os produtos que pretende que sejam associados aos menus.

Na criação do produto”menu” deve-se ter em consideração que seleciona no produto a opção menu.

Importante: Esta opção aparece ativa unicamente quando tem associado um ponto de venda: PTCert, ZS REST ou Winrest.

Configuração do Menu

Após ativar o produto como menu tem que efetuar a sua configuração.

Neste passo vai definir quais os produtos que compõem o menu.

Depois de marcar o produto como menu irá ter desbloqueado o separador para construir o menu; seleccione.

Esta é a disposição que vai encontrar para criar o seu menu.

Começamos por criar a Opção 1: pode ser uma entrada. Edite o nome no ícone de lápis e indique se pretende que essa escolha seja obrigatória (unicamente para ZSREST) ou que possa ser ignorada.

Depois de criada a opção vamos associar-lhe os produtos.

Pressionamos a opção de >>+ componente à Opção.

Escolhemos os produtos e podemos indicar se determinada escolha vai ter um custo extra para o cliente. Por exemplo; a sopa de crustáceos poderá custar +0,50€ do que as outras sopas. No campo de >> preço extra >> colocamos esse valor.

Nota: o campo ZS identifica o ponto de venda integrado com o NET-BO, só opções ZSRest.

Podemos adicionar várias opções para constituir o menu, entre opcionais na escolha ou obrigatórias.

Copiar e colar menu ou componentes de opções

O menu apresenta uma opção facilitadora que é copiar o menu ou copiar unicamente produtos de uma determinada opção; ou colar a informação que copiamos de outro menu para o que estamos a criar.

Basta estar nos componentes que pretende copiar e efetuar a ação e ir para a opção nova e efetuar colar.

A mesma ação deve ser feita para copiar menus para os produtos.

Assim, quando tiver num menu sempre as mesmas componentes na opção bebidas não terá que pesquisar as bebidas uma a uma, pode copiar todas de uma vez.

Finalize o menu efetuando gravar.

Deverá adicionar o menu ao teclado e sincronizar com o ponto de venda.

Associação do menu aos teclados

Depois de criado o produto “menu” e criados os produtos componentes desse menu vai associar a >> Gestão FO >> Teclados.

Clique 2 vezes sobre o teclado existente para associar-lhe produtos.

Se não tem a família onde pretende inserir o menu, crie a família e subfamília na opção de +.

Se a família e subfamília já existem, desdobre as mesmas clicando 2 vezes sobre elas e pesquise o produto que criou como menu para associar ao teclado. Use o ícone de lupa.

Se um produto já existir no teclado, vai receber essa informação.

Pode também criar um produto no teclado diretamente, por exemplo, caso se tenha esquecido de algum componente do menu e para não voltar atrás. Para isso use o ìcone de +.

Imagine que criou vários menus e pretende associar todos os menus com a palavra menu no nome ao teclado; ao pesquisar menu vai-lhe aparecer todos os menus. Pode usar a opção de >> adicionar todos ao teclado >> para associar todos de uma vez.

Finalize gravando alterações.

Para ter acesso ao novo teclado no ponto de venda deve >> Exportar >> o teclado para a sincronização ser efetuada com sucesso para as lojas associadas a esse teclado.
