Acesso ao NET-BO

Para iniciar a configuração do relógio de ponto e de um terminal de Face ID, deve ter acesso ao NET-BO da empresa. Se ainda não tiver, solicite a licença para suporte@opalaconsult.com.

Na opção >> Tabelas >> utilizadores deverá criar um utilizador na opção de + ou editar no caso deste já existir, clicando duas vezes sobre a linha do nome do utilizador.

Criação de utilizador

Ao criar o utilizador escolha de imediato o tipo de acesso, devendo escolher >> Sem Acesso/ Relógio de Ponto << pois só terá que caracterizar o nome do funcionário.

Escolha o separador de >> Organização << para tirar uma foto; pode também fazê-lo pelo aplicação1; deve ser o mais próximo possível da face; ou efetuar upload de uma foto previamente criada.

Escolha a empresa e /ou loja a associar o funcionário.

O funcionário só fica associado a uma loja ou armazém. Se tiver acesso através de face ID a várias lojas ou armazéns, deverá duplicar o funcionário e mudar a loja em >> Organização.

Perfil de acessos

O perfil de acesso para o relógio de ponto está criado de sistema pelo que não precisa de efetuar qualquer configuração para que este seja ativado.

Configuração do Software Cliente para ligar o terminal FACE ID

Comece por ligar o terminal à rede através de cabo de rede. Ligue também a fonte de alimentação.

O terminal vai arrancar.

Configurar a rede

Depois de arrancar no canto superior direito, pressionem para efetuar as configurações.

A password a inserir é “admin” e não pode ser alterada.

O terminal não pode/deve ser ligado por wireless para não comprometer a troca de IP’s.

Escolher a opção >> System Config

Escolha a opção de rede por cabo: wired network

Insira o IP do servidor

Ponto de Venda ou Escritório: NET-BO Client

Na máquina de escritório ou ponto de venda deverá abrir o NET-BO e efetuar donwload do Client.

Que software de Client escolher?

Windows

Se a máquina em que o for instalar estiver com o sistema operativo windows deverá efetuar download da pasta Client para windows AQUI.

Instale o setup29.exe no pc, na raiz.

O Client fica automaticamente instalado no arranque rápido do windows pelo que não tem que ter essa preocupação.

Para finalizar o processo, faça download do ficheiro config.xml AQUI e coloque dentro da pasta NETBO/ETC.

Alterações a aplicar no ficheiro config.xml

Linux - PT-CERT

Deverá aceder ao configurador da máquina e ativar o parâmetro:

geral) usa cliente NetBO

Depois, abrir um terminal e executar:

cd /root/
wget de.net-bo.com/downloads/setup_attendance.tgz
tar zxvf setup_attendance.tgz
rm setup_attendance.tgz

Copiar o ficheiro config.xml para /root/weckOFFICE/etc/

Para arrancar o programa, executar:

/root/weckOFFICE/bin/tray_application

Linux - WinREST

Se a máquina em que o for instalar estiver com uma distribuição linux deverá efetuar download; abrir o terminal:

cd /home/
wget de.net-bo.com/downloads/setup29.tgz
tar zxvf setup29.tgz
rm setup29.tgz

Copiar o ficheiro config.xml para /home/weckOFFICE/etc/

Para instalar e sincronizar:

/home/weckOFFICE/bin/start &
