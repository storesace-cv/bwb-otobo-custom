Os widgets no net-bo são componentes modulares que facilitam a integração de diversos recursos e funcionalidades na interface do utilizador da aplicação.

Cada widget é projetado para realizar uma tarefa específica e pode ser configurado e personalizado conforme as necessidades dos utilizadores. Este documento contém as especificidades para se criar um widget.

Ficheiros obrigatórios

Cada Widget é composto por, no mínimo, dois ficheiros: index.html e widget.json.

Exemplo completo de widget.json

{
  "name": "Widget de Exemplo",
  "description": "Este é um widget de exemplo.",
  "access": "*",
  "author": "Equipa NET-BO",
  "category": "Exemplos",
  "icon": "",
  "tags": ["exemplo", "widget"],
  "version": "1.0.0",
  "config_params": [],
  "filter_params": []
}

Filter Params

Os filtros necessários para o widget são declarados na raiz do ficheiro JSON. A propriedade filter_params é um array de objetos.

"filter_params": []

Preço de Custo — Cost Price

{
  "type": "cost_price",
  "label": "Preço de Custo a Usar"
}

Construção de Filtros e Config Params

Filtros

  • CustomPageViewer.vue → initializeFilterValues(): definir os defaults dos filtros na página.
  • CustomPageFiltersRenderer.vue: colocar os seletores dos filtros.
  • CustomPageEditor.vue: editar o objeto filterTypeOptions para adicionar um novo tipo de filtro. Se houver opções custom dentro desse filtro, adicionar em <div class="filters-list-section">.
