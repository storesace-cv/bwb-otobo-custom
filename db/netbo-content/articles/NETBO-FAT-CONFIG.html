Configurar a empresa

Para configurar a empresa no NET-BO deverá aceder ao seu perfil no canto superior direito e selecionar a opção >> configurações de empresa.

Utilize a opção de encolher o menu lateral esquerdo para ganhar espaço de visualização e percorra as opções de configuração da empresa para garantir que ficam todos os campos preenchidos.

Dados fiscais

Para configurar os dados fiscais. Deverá escolher no menu lateral a opção >> Tabelas >> Empresas.

A empresa estará criada por defeito. Deverá clicar 2 vezes em cima do nome para editar os respectivos campos.

Não se pode esquecer de inserir o utilizador e a password de comunicação de séries à AT para poder faturar e comunicar guias entre os restantes documentos fiscais. Encontra esta opção em >> dados fiscais.

Caso não saiba como criar um utilizador para comunicar séries, consulte AQUI.

Configurar AT-CUDs

A configuração de AT-CUD’s está também presente na ficha da empresa, logo a seguir a dados fiscais.

Para iniciarmos a criação de uma fatura, existem alguns trâmites legais a serem cumpridos. Um deles será a criação do código único ATCUD.

Segue uma breve descrição do que é o ATCUD; clique AQUI para saber como criar um utilizador para comunicar ATCUD.

“O que é o ATCUD? O Código Único de Documento, ou ATCUD, é, tal como o nome por extenso indica, um código único que visa identificar um documento fiscal (como uma fatura ou uma nota de crédito), atribuído com base num código de validação da série documental atribuído pela AT (Autoridade Tributária e Aduaneira).”

Existem duas formas atualmente para criar esses mesmos códigos:

? Manualmente - Através do portal das finanças, poderá criar na sua conta os códigos ATCUD.

? Automaticamente - Através do próprio NET-BO, ao efetuar a configuração do seu utilizador/conta das finanças para obter os dados ATCUD.

Após definir os seus dados de acesso à AT, estamos prontos para comunicar os códigos ATCUD. Para isso temos de aceder à opção AT-CUD e selecionar >> Obter ATCUD.

O NET-BO irá declarar os documentos e obter o código ATCUD para os mesmos, finalizando assim este processo. Caso os dados de acesso à AT não estejam corretos será mostrado um erro..

No caso de não obter os códigos na totalidade e devolver algum com erro, carregue várias vezes no botão >> Obter ATCUD até que todos sejam preenchidos
